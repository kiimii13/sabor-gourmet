Reglas de Negocio y Arquitectura de Sabor Gourmet

Especificación técnica y de dominio implementada en el sistema.

Duración Fija de Turnos

Cada reserva confirmada tiene una duración fija de 120 minutos (2 horas). El sistema nunca almacena un campo endTime en la base de datos; éste siempre se calcula dinámicamente sumando 120 minutos a startTime.

Capacidad Máxima del Restaurante

El restaurante opera con un inventario estricto de máximo 10 mesas. Registrar una 11ª mesa es bloqueado por el servidor con un código HTTP 409 Conflict.

Cancelación Segura (Historial)

Las cancelaciones no borran el registro del sistema: su estado cambia a CANCELLED, preservando la trazabilidad. Una reserva cancelada libera inmediatamente la mesa asignada para nuevos clientes.

Integridad Referencial

No se permite eliminar clientes ni mesas que tengan reservas asociadas. Primero debe desvincularse o cancelarse la reserva antes de intentar la eliminación.

Zona Horaria Estricta

Todas las comparaciones de hora actual y consultas por día se realizan bajo la zona horaria America/Santiago.

Capa CSR & Persistencia JSON

Separación estricta Controller → Service → Repository. Persistencia centralizada en el archivo JSON data/sabor-gourmet.json.
